**PluX** — это специализированное внешнее решение для работы с памятью процессов на Android. Обеспечивает стабильную связь между игровым движком и инструментами исполнения.

## 🛠 Механика работы
Инструмент использует технологию **Memory Stitching**, которая «сшивает» функционал PluX с активным процессом экзекутора. Это позволяет обходить современные системы защиты, такие как Hyperion.

## 🚀 Основные характеристики
* 🛡 **Hyperion Bypass:** Обход защиты через внешнее чтение памяти.
* 📱 **Поддержка Android:** От **7.0** до **16.0**.
* ⚡ **RAM:** Минимум **4 GB RAM**.
* ✅ **Verified Executor:** **Delta (All Versions)**.

## 🔌 Статус исполнителей (Executors)
* **Delta:** Поддерживается официально.
* **Остальные:** В процессе верификации (Under Verification).
