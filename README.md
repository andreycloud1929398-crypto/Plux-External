## ⚡ Описание
**PluX** — это внешнее решение для Android, которое внедряется в существующий экзекутор и работает напрямую с памятью процесса. Это обеспечивает высокую стабильность и защиту от обнаружения.

## 🚀 Основные фишки
- ✅ **Hyperion Bypass:** Полный обход защиты.
- ✅ **Delta Support:** Стабильная работа со всеми версиями Delta.
- ✅ **External Engine:** Не нагружает систему, работает через чтение памяти.
- ✅ **Wide Support:** Поддержка всех актуальных версий Android (7-16).

## 🛠 Требования
* **RAM:** Минимум 4 GB.
* **OS:** Android 7.0 и выше.
* **Executor:** Наличие установленного Delta.
