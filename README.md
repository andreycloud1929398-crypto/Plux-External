# 🌌 PluX External Engine
**PluX** — это высокопроизводительный внешний инструмент для работы с памятью игровых процессов на платформе Android. Проект сфокусирован на скрытности и стабильности, работая как надстройка над существующими игровыми средами.
## 🛠 Техническая реализация
Инструмент реализует метод **External Memory Stitching**. Вместо традиционного внедрения кода (Injection), PluX связывается с процессом активного экзекутора, считывая и модифицируя данные в реальном времени. Это позволяет обходить современные системы защиты, такие как Hyperion.
## 🚀 Ключевые возможности
* 🛡 **Hyperion Memory Bypass:** Технология прямого чтения памяти в обход встроенных анти-читов.
* 📱 **Версии Android:** Полная поддержка от **7.0 (Nougat)** до **16.0 (Latest)**.
* ⚡ **Оптимизация:** Минимальное потребление ресурсов; требуется **4 GB RAM** для стабильной работы.
* 🧩 **UI:** Минималистичный темный интерфейс с акцентом на удобство использования.
